# Сегментация сосудов сетчатки при сильном дисбалансе классов

Проект посвящён бинарной сегментации сосудов сетчатки на датасете DRIVE. Исследовалось влияние архитектуры, функции потерь, предобработки и аугментаций на качество выделения редкого класса сосудов.

Лучшая среди протестированных конфигураций — **SA-UNetv2 + 0.5 BCE + 0.5 MCC**, получившая **Dice 0.7845** и **IoU 0.6454** на валидационной выборке.

## Ключевые результаты

| Конфигурация | Предобработка | Dice | IoU |
|---|---|---:|---:|
| **SA-UNetv2 + BCE + MCC** | RGB | **0.7845** | **0.6454** |
| U-Net + BCE | Green Channel + CLAHE | 0.7547 | 0.6060 |
| U-Net + BCE — baseline | RGB | 0.7438 | 0.5921 |

Всего в основном исследовании сравнены 12 конфигураций: различные функции потерь, методы предобработки, аугментации и архитектуры. Дополнительно проведён отдельный эксперимент с joint pixel/segment-level loss.

## Данные

Использован датасет [DRIVE — Digital Retinal Images for Vessel Extraction](https://drive.grand-challenge.org/).

Датасет не хранится в репозитории. Для запуска ноутбуков его необходимо скачать отдельно с официального сайта.

## Ограничение исследования

Green Channel + CLAHE улучшил baseline U-Net + BCE: Dice вырос с 0.7438 до 0.7547. Однако эта предобработка не проверялась совместно с итоговой SA-UNetv2 + BCE + MCC.

Поэтому SA-UNetv2 на RGB рассматривается как лучшая **среди протестированных конфигураций**, а сочетание SA-UNetv2 с Green Channel + CLAHE остаётся направлением дальнейшего исследования.
